# Limites deste projeto

Este repositório é o projeto `origemazul-camarao`, correspondente ao site Origem Azul.
A pasta local ainda pode se chamar `camarao-producao-site` enquanto a renomeação estiver pendente.

- `C:\SITES AGENCIA ESTALO\producao-de-camarao` é outro projeto e outro repositório Git.
- `C:\SITES AGENCIA ESTALO\Camarao-do-norte` também é outro projeto e outro repositório Git.
- Não criar, copiar, exportar ou publicar arquivos deste site nessas pastas. Não alterar os remotes, arquivos ou histórico desses projetos sem uma solicitação específica do usuário.
- Guardar artefatos temporários, arquivos de publicação e arquivos compactados em `outputs/` deste repositório, que já está ignorado pelo Git. Se um helper não aceitar esse destino, usar o diretório temporário do sistema; nunca usar outro projeto como destino alternativo.
- O repositório do GitHub deste projeto deve ter identidade própria: `origemazul-camarao`. Não apontar este projeto para o remote `producao-de-camarao`.
- Antes de commit ou push, conferir o diretório raiz e o remote selecionado. Não inventar um remote nem publicar no GitHub até que o repositório de destino deste projeto tenha sido confirmado.
